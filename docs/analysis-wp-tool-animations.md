# `C:\wp-tool\動畫特效` 適用性評估

> 評估對象：10 組「純 CSS + Vanilla JS」動畫（原本給 WordPress 貼上用）。
> 評估依據：志願分組的使用情境——**組員用手機掃 QR 進來、花 1～3 分鐘填表單就離開**；主辦方偶爾回來看進度。
> 所以動畫的原則是：**填表單時不能干擾操作、手機上不能卡、要尊重「減少動態效果」設定**；
> 動畫應該集中在「進場、送出、公布結果」這些有情緒起伏的時刻。

## 判定標準

| 標準 | 說明 |
|---|---|
| 情境契合 | 這個效果放在這裡是否「有意義」，而不只是好看 |
| 手機成本 | 是否依賴滑鼠（手機沒有 hover）、是否吃 GPU（大面積 blur） |
| 干擾風險 | 是否會影響拖曳排序、輸入、閱讀 |
| 實作成本 | 專案已有 framer-motion + Lenis，能重用就不重寫 |

## 逐項說明

### 01 捲動淡入 — 已涵蓋
`src/components/motion.tsx` 的 `RevealCard`（framer-motion `whileInView`）已套用在活動頁、後台、列表所有卡片。
原版 CSS/JS 用 IntersectionObserver，功能重疊，直接略過。

### 02 數字計數 — 可選
- 可用位置：主辦方後台「已填寫 X / N 人」。
- 缺點：這個數字通常是 0～30 的小數字，計數動畫幾乎看不出來；輪詢更新（每 15 秒）時每次重跑會很吵。
- 若要做：只在「數字變大」時做一次短滾動（≤ 400ms），首次載入直接顯示。

### 03 視差背景 — 不做
沒有 Hero 大圖，頁面是單欄表單；視差還會和 Lenis 平滑捲動、OverscrollBounce 互相疊加，容易造成手機暈眩與掉幀。

### 04 卡片懸浮傾斜 — 有條件
- 適合：首頁兩顆按鈕卡、`/activities` 的活動卡（純「點進去」的卡片）。
- 不適合：填志願的卡片（正在拖曳 `dnd-kit` 的區域）、輸入框附近——3D transform 會讓 pointer 座標判定偏移。
- 必須限定 `@media (hover: hover) and (pointer: fine)`，手機不啟用。

### 05 文字逐字浮現 — 適合
首頁標題「志願分組」四個字逐字浮現，延遲 60ms/字，總長 < 0.5s。
用 framer-motion 的 `variants` + `staggerChildren` 即可，不需引入新東西。

### 06 磁性按鈕 — 僅桌面
只套在首頁兩顆 CTA。吸附半徑小（≈ 60px）、位移上限 8px，離開回彈。
手機用既有的 `tap-bounce`（按下縮放彈回）就夠了。

### 07 文字亂碼解密 — 最推薦
公布結果那一刻：
- 組員頁：「你被分配到」→ 職位名稱亂碼跳動約 700ms → 解出真正職位。
- 這是整個產品「情緒最高」的瞬間，值得花動畫。
- 注意：**只在「第一次看到結果」時播放**（用 localStorage 記已看過），之後重整不再重播；`prefers-reduced-motion` 時直接顯示結果。
- 無障礙：亂碼期間 `aria-label` 要直接是最終文字，避免螢幕閱讀器念亂碼。

### 08 漸層網格背景 — 已採用
- 原版是純 CSS 多層 radial-gradient + animation。實作時改成 3 顆 `filter: blur` 的圓形光球（紫 / 青 / 洋紅）緩慢漂移，比較貼近使用者給的截圖。
- 只在 `data-theme="dark"` 顯示，淺色模式完全不渲染。
- 手機 blur 從 90px 降到 60px（降 GPU 成本）；`prefers-reduced-motion` 時停止漂移只留靜態光暈。
- `position: fixed` 放在 `Providers` 外，不受 OverscrollBounce 的 transform 影響。

### 09 游標聚光燈 — 建議不做
深色模式已有大面積光暈，再加跟著游標的光斑會搶戲；且和新加的「點擊光環」語意重疊（都是「游標附近發光」）。手機無游標，收益只在桌面。若之後想要，優先做成「hover 卡片時卡片邊緣微亮」而非全域聚光。

### 10 無限跑馬燈 — 不做
沒有適用內容。

## 建議的後續順序（若要繼續做）

1. **07 文字亂碼解密**（公布結果）— 價值最高
2. **05 逐字浮現**（首頁標題）— 半小時內可完成
3. **06 磁性按鈕**（桌面首頁 CTA）— 需要 `pointer: fine` 判斷
4. 04 卡片傾斜（活動列表）— 視情況
5. 02 數字計數、09 聚光燈 — 低優先

## 通用注意事項（不論做哪個）

- 一律遵守 `prefers-reduced-motion`；專案已用 `MotionConfig reducedMotion="user"`，純 CSS 動畫要另外寫 media query。
- 大面積 `blur` / `backdrop-filter` 只用在深色背景與卡片，手機要降半徑。
- 不要在 `dnd-kit` 拖曳區域內的元素加 transform 類 hover 效果。
- 動畫元素離開畫面時暫停（IntersectionObserver）——目前 mesh 背景是 fixed 全程可見，用 CSS 動畫由瀏覽器自行降頻，尚可接受。
